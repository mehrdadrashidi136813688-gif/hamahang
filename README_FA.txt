هم‌آهنگ - پروژه ساخت APK

این نسخه آزمایشی آفلاین است. داده‌ها روی همان گوشی ذخیره می‌شوند؛ حساب‌ها بین گوشی‌ها مشترک نیستند و OTP واقعی ارسال نمی‌شود.

ورود آزمایشی:
- شماره مدیر: 09156170125 (معادل +989156170125)
- کد OTP آزمایشی: 1234
- PIN مدیر: 2580
- کاربران دیگر با شماره 09xxxxxxxxx و OTP 1234 ثبت‌نام کنند.

ساخت APK آسان از طریق GitHub Actions:
1) یک Repository جدید در GitHub بسازید.
2) محتویات این ZIP را داخل repository آپلود کنید.
3) به تب Actions بروید و workflow با عنوان Build Android APK را انتخاب کنید.
4) Run workflow را بزنید و منتظر سبز شدن build بمانید.
5) از صفحه اجرای workflow پایین بخش Artifacts، hamahang-apk را دانلود کنید.
6) ZIP artifact را باز کنید و app-debug.apk را روی اندروید نصب کنید. اگر Android اجازه نصب داد، Install unknown apps را برای برنامه فایل‌ها/مرورگر فعال کنید.

این فایل پروژه آماده build است، اما در این محیط ابزار Android SDK/Gradle برای کامپایل APK مستقیم نصب نیست؛ پس APK واقعی در همینجا تولید نشده است.
