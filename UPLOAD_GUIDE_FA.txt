راهنمای به‌روزرسانی مخزن GitHub با پروژه هماهنگ نسخه ۴

۱) فایل ZIP را در لپ‌تاپ دانلود و Extract کنید.
۲) محتویات استخراج‌شده را ببینید؛ باید پوشه app، پوشه .github و فایل‌های Gradle در ریشه باشند.
۳) فقط ZIP را به مخزن آپلود نکنید؛ فایل‌های پروژه باید در ریشه مخزن قرار بگیرند.
۴) فایل‌ها/پوشه‌های جدید را در مخزن HamAhang2 روی شاخه main جایگزین کنید؛ پوشه .github/workflows را حتماً نگه دارید.
۵) Commit کنید. با Push به main، Workflow ساخت APK اجرا می‌شود.
۶) در Actions، اجرای سبز Build Hamahang Signed APK را باز کنید و Artifact را دانلود کنید.

نکته: فایل Keystore و رمز آن در این ZIP نیستند. Workflow از Secrets فعلی GitHub استفاده می‌کند. نسخه قبلی برنامه را تا نصب و آزمایش APK جدید حذف نکنید.
